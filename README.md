# Nightland

Expo (SDK 57) / React Native game. Routes live in `routes/` (thin Expo Router entries); implementation lives in `app/`, `components/`, `modules/`, `state/` and `config/`. Design notes are in `docs/`.

## Develop

```bash
pnpm install
pnpm start        # npx expo start
pnpm check        # format, lint, typecheck, tests
```
